# Inhalt und Qualität
Stand: 19.10.2026

Zweck: Richtlinie für Aufgaben und Module beider Labore: Eigenleistung, Prüfprozess, Fehlermeldungen, Änderungsprotokoll. Keine Rechtsberatung.

## Eigenleistung (entschieden 19.10.2026)
- Entschieden: Jede Aufgabe entsteht aus einem Lernziel des Rahmenplans, nie aus einer Prüfungsaufgabe als Vorlage. Siehe [ADR 002](adr/002-abstandsregel-pruefungsaufgaben.md).
- Entschieden: Alte Prüfungsaufgaben werden nur ausgewertet, nicht beim Schreiben offen gehalten. Aus der Auswertung entsteht eine Liste „Thema, Aufgabenart, Schwierigkeit“ (Beispiel: „Hydraulik, Kolbenkraft berechnen, mittel“).
- Erlaubt: gleiche Themen, gleiche Aufgabenarten (berechnen, erläutern), ähnliches Punkteschema.
- Nicht erlaubt: übernommene Sachverhalte, Formulierungen, Zahlenkombinationen oder Gliederungen.
- Jede Aufgabe hat ein eigenes Betriebsbeispiel und eigene Zahlen.

## Prüfprozess
- Annahme: Markus prüft vor jedem Kurs-Samstag die Module, die er als nächste Aufgabe gibt, selbst fachlich durch.
- Offen: Zweite Person für die fachliche Prüfung vor einem Verkauf an Träger.

## Fehlermeldungen
- Entschieden: Knopf „Fehler melden“ je Aufgabe, öffnet eine vorausgefüllte E-Mail mit Modul, Aufgabe und gezogenen Zufallswerten. Eigene Projekt-E-Mail-Adresse, weil sie öffentlich im Code steht.

## Rechtsstand
- Annahme: NTG ist von Gesetzesänderungen kaum betroffen (Physik, Chemie, Statistik). Für das Meisterlabor (vor allem ReHa, BeHa) ist der Rechtsstand zentral und wird später geklärt.

## Umfang (Block D, entschieden 19.10.2026)
- Bestand Lernlabor: rund 50 Themen (Mathe-Grundlagen, Mechanik, Hydraulik/Pneumatik, Wärme, Elektrotechnik, Chemie, Statistik/Qualität).
- Entschieden: Vor dem Pilot keine neuen Themen. Lücken werden über den Knopf „Fehler melden“ und die Zwischenumfrage gesammelt.
- Annahme: Lernlabor und Meisterlabor bleiben bis nach dem Pilot getrennt (kein gemeinsamer Lernstand, keine gemeinsame Navigation).
- Bewusst nicht enthalten: IHK-Originalaufgaben und Abwandlungen davon; im Pilot keine KI-Funktionen.

## Änderungsprotokoll
- Vorhanden: Jede Änderung ist ein Commit im Repo; die Cache-Version in sw.js wird je Update erhöht (Stand v30).
- Entschieden: Die Startseite zeigt eine kurze Zeile „Neu in Version N: …“, damit Teilnehmer sehen, dass Fehlermeldungen etwas bewirken.
