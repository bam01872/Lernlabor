# Lernlabor installieren
Stand: 19.10.2026

Zweck: Anleitung für Teilnehmer am ersten Kurs-Samstag. Zum Ausdrucken oder Vorführen am Beamer.

**Adresse:** https://84g64ds8jm-cmyk.github.io/LernLabor/
(Vor dem Ausdrucken einmal im Browser prüfen, ob die Adresse stimmt.)

## Warum installieren?
- Dein Lernstand liegt nur auf Deinem Gerät. Auf dem iPhone löscht Safari die Daten einer Webseite, wenn Du sie 7 Tage nicht öffnest. Als installierte App passiert das nicht.
- Die installierte App läuft auch ohne Internet, nachdem Du sie einmal online geöffnet hast.

## iPhone und iPad
1. Öffne die Adresse in **Safari**.
2. Tippe unten auf das **Teilen-Symbol** (Quadrat mit Pfeil nach oben).
3. Scrolle nach unten und tippe auf **„Zum Home-Bildschirm“**.
4. Tippe oben rechts auf **„Hinzufügen“**.
5. Öffne das Lernlabor ab jetzt nur noch über das **neue Symbol auf dem Home-Bildschirm**, nicht mehr über Safari.

## Android (Handy und Tablet)
1. Öffne die Adresse in **Chrome**.
2. Tippe oben rechts auf die **drei Punkte**.
3. Tippe auf **„App installieren“** oder **„Zum Startbildschirm hinzufügen“**.
4. Bestätige mit **„Installieren“**.
5. Öffne das Lernlabor ab jetzt über das **neue Symbol**.

## Laptop (Windows oder Mac)
1. Öffne die Adresse in **Chrome** oder **Edge**.
2. Klicke rechts in der Adresszeile auf das **Installieren-Symbol** (Bildschirm mit Pfeil).
3. Klicke auf **„Installieren“**.
4. Das Lernlabor öffnet sich jetzt in einem eigenen Fenster und hat ein Symbol im Startmenü oder Dock.

Hinweis: Firefox kann Web-Apps auf dem Laptop nicht installieren. Nimm dafür Chrome oder Edge.

## Lernstand sichern (vor jedem Kurs-Samstag)
1. Öffne das Lernlabor.
2. Tippe auf der Startseite auf **„Zum Lernstand →“**.
3. Scrolle zum Bereich **„💾 Daten“**.
4. Tippe auf **„Exportieren“**. Es wird eine Datei `lernlabor-lernstand-DATUM.json` gespeichert.
5. Bewahre die Datei auf (zum Beispiel in Deinen Dateien oder per E-Mail an Dich selbst).

**Auf ein anderes Gerät übertragen:** Auf dem neuen Gerät im selben Bereich auf **„Importieren“** tippen und die Datei auswählen.
