# Faraday-Konstante (aus der App genommen in v259, 08.11.2026)

Die Faraday-Konstante geht über den Stoff des NTG-Kurses hinaus. Seit v258 rechnen die Elektrolyse-Aufgaben mit der Ladung in Amperestunden und einer vorgegebenen Abscheiderate (Kupfer 1,19 g/Ah, Zink 1,22 g/Ah, Aluminium 2980 Ah/kg). Teilaufgaben, die F brauchten, sind gestrichen.

`original-v257.txt` enthält alle ersetzten Stellen aus index.html v257 im Original (Aufgaben, Aufträge, Erklärungen, Formelsammlung, Glossar). Zum Wiederherstellen die betreffende Zeile in index.html durch das Original ersetzen, Version hochzählen, `node tests/check.js` laufen lassen.
